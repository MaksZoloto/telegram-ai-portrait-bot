# Сценарий 60-секундной демонстрации

Цель ролика — показать работающий бизнес-процесс, а не листать весь код.

## Последовательность

1. Запустить бота и выбрать язык.
2. Загрузить нейтральную тестовую фотографию.
3. Выбрать стиль портрета.
4. Показать локальную demo-генерацию.
5. Открыть код адаптера Leonardo и объяснить заменяемый provider.

## Правила записи

- используйте только тестовые данные и нейтральные файлы;
- не показывайте `.env`, консоль с токеном, IP сервера или закрытые ссылки;
- держите ролик в пределах 45–90 секунд;
- в описании дайте ссылку на README и `CASE_STUDY.md`;
- завершите конкретным результатом для пользователя или бизнеса.
